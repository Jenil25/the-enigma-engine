# The Enigma Engine

**The Enigma Engine** is a comprehensive Escape Room Management System designed to handle customer bookings, live game operations, puzzle management, and financial reporting.

## Features
- **Customer Portal**: Browse rooms, book slots, pay invoices.
- **Game Master Dashboard**: Manage live sessions, log hints, track success.
- **Admin Console**: Manage rooms, puzzles, staff, and view analytics.
- **Data Analysis**: Insightful reports on room difficulty, revenue, and player performance.

## Tech Stack
- **Frontend**: Next.js (TypeScript), Tailwind CSS
- **Backend**: Flask (Python)
- **Database**: SQL (SQLite/MySQL)
- **Containerization**: Docker
